# Task Templates

## Feature/Milestone

```markdown
Problem
[What's broken, missing, or needed]

Solution
[High-level approach]

What Ships
- Deliverable 1
- Deliverable 2
- Deliverable 3

Out of Scope
- Future work
- Related but separate

Impact
[Who benefits, how]
```

## Bug

```markdown
Problem
[What's broken - include error messages]

Expected
[Correct behavior]

Repro
1. Step
2. Step
3. Bug

Environment
- Marketplace:
- Account:
```

## Tech Debt

```markdown
Problem
[Current state issue]

Impact
[Performance/maintainability/bugs caused]

Proposal
[Approach]
```

## Completion Comment

Add when shipping:

```markdown
Completed
- What was done
- Deviations from plan

PR
- [link]

Notes
- Gotchas
- Follow-up items
```

## Naming

Pattern: `[Action] [Thing] [Context]`

Examples:
- Add barcode as product identifier
- Handle Amazon cancelled orders
- Sync missed orders from Trendyol

Avoid: "Backend", "Demo", "API calls", "Update"

## Minimum Required

1. Specific name
2. Problem statement
3. Done criteria
